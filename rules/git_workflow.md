# Craftsman Global Engineering & Git Workflow Rules

## Git & Repository Hygiene
1. **No Unconfirmed Push to `main` / `master`**:
   - NEVER run `git push` directly to `main` or `master` without first asking the user for explicit confirmation (via `ask_question` or direct interactive prompt), offering a choice between pushing to a new feature branch for a Pull Request vs. pushing directly to `main`.
2. **Author Identity & Zero AI Attribution**:
   - Always author and commit changes strictly as the repository's configured human user (`git config user.name` and `git config user.email`).
   - NEVER add `Co-authored-by:`, `Generated by`, `Generated with`, or any AI attribution trailers to commit messages, tags, or pull requests.
3. **Atomic Conventional Commits**:
   - When committing changes, split unrelated concerns into logical, atomic commits using Conventional Commits format (`feat`, `fix`, `refactor`, `perf`, `test`, `docs`, `chore`) in American English.
4. **Disk & Workspace Hygiene**:
   - Avoid spawning file-heavy multi-agent orchestrations that pollute the workspace with temporary `.md` scratch files unless explicitly requested. Prefer direct in-context execution or clean in-memory subagents.
