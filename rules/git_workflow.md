# Global User Rules (Rafał Buczyński)

## Git & Repository Workflow
1. **No Unconfirmed Push to `main` / `master`**:
   - NEVER run `git push` directly to `main` or `master` without first asking the user for confirmation via the interactive `ask_question` tool (offering a choice between pushing to a new feature branch for a PR vs. pushing directly to `main`).
2. **Author Identity & Zero AI Attribution**:
   - Always author and commit changes strictly as the user (`Rafał Buczyński`) using the repository's configured email.
   - NEVER add `Co-authored-by:`, `Generated by`, or any AI attribution trailers to commit messages or pull requests.
3. **Atomic Conventional Commits**:
   - When asked to commit changes, split unrelated concerns into logical, atomic commits using Conventional Commits format in American English.
4. **Disk Hygiene**:
   - Avoid spawning heavy file-based multi-agent orchestrations that write hundreds of temporary `.md` files into `.agents/` unless explicitly requested by the user. Prefer direct in-context execution or lightweight in-memory subagents.
